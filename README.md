# Python Developer Internship - Oasis Infobyte

Three small Python utilities built during the internship.

[![Python](https://img.shields.io/badge/python-3.10%2B-blue?style=flat-square&logo=python&logoColor=white)](https://www.python.org/)

---

## Tasks

| # | Task | What it does |
|---|---|---|
| **2** | **BMI Calculator** | Takes height and weight, returns BMI and the corresponding category |
| **3** | **Password Generator** | Generates passwords to a chosen length and character-class mix |
| **4** | **Weather App** | Fetches current conditions for a city from a weather API and formats the result |

## Run them

```bash
git clone https://github.com/dhruvg0ya1/Projects-Python-Developer-Internship-Oasis-Infobyte.git
cd Projects-Python-Developer-Internship-Oasis-Infobyte

python "Task 2: BMI Calculator.py"
python "Task 3: Simple Password Generator.py"
python "Task 4: Weather App.py"
```

The weather app needs an API key; set it as an environment variable before
running.
